# company-sales-ddd-clean-architecture

## Propósito

Este projeto foi criado como uma demonstração prática de conhecimentos em **DDD (Domain-Driven Design)** e **Clean Architecture**.

O objetivo é oferecer uma visão clara da minha forma de estruturar software, organizar regras de negócio e separar responsabilidades, para que recrutadores e membros da área técnica possam avaliar minhas decisões de arquitetura e implementação.

## Status da documentação

Esta é uma documentação inicial. Conforme o projeto evoluir, novas seções serão adicionadas com mais detalhes sobre contexto de negócio, decisões técnicas, estrutura das camadas, casos de uso e demais aspectos relevantes.
